Welche E-Mails und Mitteilungen Sie erhalten, wählen Sie unter **Mein Konto › Benachrichtigungen**. Jede Person in Ihrem Team stellt das für sich ein. Sicherheits-E-Mails kommen immer.

Wochenübersicht, Monatsbericht und Neue Anfragen schalten Sie dort ein oder aus.

## E-Mails zu Ihrem Assistenten

| E-Mail | Wann |
| --- | --- |
| **Wochenübersicht** | jeden Montag: Gespräche, beantwortete Fragen, Anfragen, gesparte Zeit und Fragen ohne Antwort |
| **Monatsbericht** | einmal im Monat: Gespräche, häufige Fragen, offene Fragen und Empfehlungen |
| **Neue Anfragen** | sobald ein Besucher eine Anfrage sendet |
| **Neuer Termin / Neue Reservierung** | bei jeder Buchung und Absage im Chat |
| **Ein Besucher möchte mit einer Person sprechen** | wenn jemand eine Person verlangt |
| **Frage nicht beantwortet** | an Inhaber und Admins, nicht für jede einzelne Frage |
| **Neue Informationen auf Ihrer Website** | wenn die [Website-Prüfung](/assistent/website-lesen) Änderungen findet |

Dazu kommen E-Mails zu Ihrem Abo, etwa wenn die Testphase endet, bei 80% und 100% Ihrer Gespräche oder wenn eine Zahlung nicht durchging.

## Mitteilungen einschalten

Unter **Gespräche** steht «Benachrichtigung, wenn jemand auf Sie wartet.». Tippen Sie auf **Einschalten**. Das gilt für dieses Gerät. Steht dort, dass Benachrichtigungen blockiert sind, erlauben Sie sie in den Einstellungen Ihres Browsers.

Unter **Mein Konto › Benachrichtigungen › Auf dem Handy** wählen Sie, was Sie erhalten:

| Mitteilung | |
| --- | --- |
| **Ein Besucher wartet** | mit den ersten Worten, auch weitergegebene Chats |
| **Erinnerung nach 2 Minuten** | einmal, wenn noch niemand geantwortet hat |
| **Besucher hat geantwortet** | nur an die Person, die den Chat hat, wenn sie nicht auf der Seite ist |
| **Neue Termine** | |
| **Neue Anfragen** | |
| **Zusammenfassung am Abend** | gegen 18:00, wie viele Fragen offen blieben. Für Inhaber und Admins, nur wenn es welche gibt |
| **Geschriebenes anzeigen** | aus: Der Sperrbildschirm zeigt keine Worte und Namen |
| **Ruhezeiten** | von … bis … keine Mitteilungen. Wartende Besucher können trotzdem durchkommen, wenn Sie das wählen |
