---
title: "Andere Websites"
description: "Eigenes HTML, ein anderes System oder der Google Tag Manager."
---

Der Code funktioniert auf jeder Website, auf der Sie eigenen Code einfügen können.

## Was Sie brauchen

- Zugang zur Vorlage oder zum Footer, den jede Seite Ihrer Website verwendet.
- Ihre Website ist unter **Einbauen › Ihre Website** eingetragen.
- Eine laufende Testphase oder einen Plan. Alle Pläne.

<Tabs>
  <Tab title="HTML oder anderes System">
    <Steps>
      <Step title="Vorlage öffnen">
        Die Vorlage oder den Footer öffnen, den jede Seite Ihrer Website verwendet.
      </Step>
      <Step title="Code einfügen">
        Den Code von **Einbauen** direkt über `</body>` einfügen.
      </Step>
      <Step title="Veröffentlichen">
        Speichern und die Website veröffentlichen.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Google Tag Manager">
    <Steps>
      <Step title="Neues Tag">
        Im Tag Manager auf **Neues Tag › Tag-Konfiguration › Benutzerdefiniertes HTML** klicken.
      </Step>
      <Step title="Code und Trigger">
        Den Code einfügen und den Trigger **All Pages** wählen.
      </Step>
      <Step title="Veröffentlichen">
        **Speichern**, dann **Senden › Veröffentlichen**.
      </Step>
    </Steps>

    «Ist er live?» sieht Code aus dem Tag Manager nicht. Öffnen Sie Ihre Website und schauen Sie, ob der Chat-Knopf erscheint.
  </Tab>
</Tabs>

## Wenn es nicht klappt

<AccordionGroup>
  <Accordion title="Der Chat erscheint nur auf einer Seite">
    Der Code muss auf jeder Seite stehen. Setzen Sie ihn in den gemeinsamen Footer oder die Vorlage, nicht in eine einzelne Seite.
  </Accordion>
  <Accordion title="Der Chat erscheint gar nicht">
    Ist die Website eingetragen und der Assistent eingeschaltet? Leeren Sie den Cache und prüfen Sie mit [Ist er live?](/start/ist-er-live).
  </Accordion>
  <Accordion title="Ich weiss nicht, wo ich den Code einfüge">
    Unter **An meinen Webentwickler senden** schicken Sie Code und Anleitung an die Person, die Ihre Website betreut.
  </Accordion>
</AccordionGroup>
