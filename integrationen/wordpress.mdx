Für WordPress gibt es ein Plugin, gemacht für Ihren Assistenten. Sie kopieren keinen Code, alles andere stellen Sie weiter im Dashboard ein.

## Was es kann

| | |
| --- | --- |
| **Chat auf jeder Seite** | unten rechts der Chat-Knopf |
| **Ohne Code** | Plugin «Lucelabs Chat» hochladen und aktivieren |
| **Aussehen** | Farben, Logo und Position unter [Aussehen](/assistent/aussehen) |
| **WooCommerce** | dazu Produktkarten, Warenkorb und Bestellstatus. [WooCommerce](/integrationen/woocommerce) |

## Was Sie brauchen

- Eine WordPress-Website, auf der Sie Plugins installieren dürfen (WordPress 5.2 oder neuer).
- Ihre Website unter **Einbauen › Ihre Website** eingetragen.
- Eine laufende Testphase oder einen Plan. Alle Pläne.

## Einrichten

<Steps>
  <Step title="Plugin herunterladen">
    Auf der Seite Ihres Assistenten unter **Einbauen** auf **WordPress-Plugin herunterladen** klicken. Sie erhalten eine ZIP-Datei.
  </Step>
  <Step title="Hochladen">
    In WordPress **Plugins › Neues Plugin › Plugin hochladen** öffnen, die Datei wählen, **Jetzt installieren**.
  </Step>
  <Step title="Aktivieren">
    Auf **Aktivieren** klicken. Der Chat ist auf Ihrer Website.
  </Step>
</Steps>

## Gut zu wissen

<AccordionGroup>
  <Accordion title="Ein Plugin pro Assistent">
    Das Plugin heisst «Lucelabs Chat» und gehört zu genau einem Assistenten. Um den Chat zu entfernen, deaktivieren Sie es.
  </Accordion>
  <Accordion title="Ohne Plugin, mit Code (WPCode)">
    Können Sie keine Plugins hochladen, nutzen Sie das Gratis-Plugin «WPCode»:

    1. In WordPress **Plugins › Installieren**, nach «WPCode» suchen, installieren und aktivieren.
    2. **Code Snippets › Header & Footer** öffnen.
    3. Den Code von **Einbauen** ins Feld «Footer» einfügen und **Änderungen speichern**.
  </Accordion>
</AccordionGroup>

## Wenn etwas nicht klappt

<AccordionGroup>
  <Accordion title="Der Chat erscheint nicht">
    Leeren Sie den Cache Ihres Cache-Plugins und laden Sie die Seite neu. Prüfen Sie dann mit [Ist er live?](/start/ist-er-live).
  </Accordion>
  <Accordion title="Ich darf keine Plugins hochladen">
    Manche Hosting-Pakete erlauben das nicht. Nutzen Sie dann WPCode oder fragen Sie die Person, die Ihre Website betreut.
  </Accordion>
  <Accordion title="Ein anderer Assistent erscheint">
    Jedes Plugin gehört zu einem Assistenten. Laden Sie es bei dem Assistenten herunter, der erscheinen soll.
  </Accordion>
</AccordionGroup>
