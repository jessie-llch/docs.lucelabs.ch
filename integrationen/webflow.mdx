Ihr Assistent kommt mit einer Zeile Code auf Ihre Webflow-Website. Danach beantwortet er Fragen Ihrer Besucher auf jeder Seite.

## Was es kann

| | |
| --- | --- |
| **Chat auf jeder Seite** | unten rechts der Chat-Knopf |
| **Aussehen** | Farben, Logo und Position unter [Aussehen](/assistent/aussehen) |
| **Produkte aus Ihrem Webflow-Shop** | als Karte mit **Produkt öffnen**. [Shop](/funktionen/shop) |
| **Anleitung im Dashboard** | auch unter **Einbauen › Wo Sie ihn einfügen** |

## Was Sie brauchen

- Ein Webflow-Plan, mit dem Sie eigenen Code einfügen und veröffentlichen können.
- Ihre Website unter **Einbauen › Ihre Website** eingetragen.
- Eine laufende Testphase oder einen Plan. Alle Pläne.

## Einrichten

<Steps>
  <Step title="Code kopieren">
    Auf der Seite Ihres Assistenten unter **Einbauen** auf **Code kopieren** klicken.
  </Step>
  <Step title="Custom code öffnen">
    In Webflow **Site settings › Custom code** öffnen.
  </Step>
  <Step title="Code einfügen">
    Den Code bei **Footer code** einfügen.
  </Step>
  <Step title="Veröffentlichen">
    Speichern, dann **Publish**.
  </Step>
  <Step title="Prüfen">
    Mit [Ist er live?](/start/ist-er-live) prüfen, ob alles stimmt.
  </Step>
</Steps>

## Gut zu wissen

<AccordionGroup>
  <Accordion title="Jemand anders betreut Ihre Website">
    Unter **An meinen Webentwickler senden** schicken Sie Code und Anleitung per E-Mail.
  </Accordion>
  <Accordion title="Webflow-Shop">
    Produkte zeigt Ihr Assistent als Karte mit **Produkt öffnen**. In den Warenkorb legen Besucher sie auf der Produktseite. [Shop](/funktionen/shop)
  </Accordion>
</AccordionGroup>

## Wenn etwas nicht klappt

<AccordionGroup>
  <Accordion title="Der Code ist gespeichert, aber nicht online">
    Webflow übernimmt Code erst mit **Publish**. Veröffentlichen Sie die Website erneut.
  </Accordion>
  <Accordion title="Der Chat erscheint nicht">
    Wurde die Website nach dem Einfügen veröffentlicht? Laden Sie die Seite neu, am besten in einem privaten Fenster. Prüfen Sie dann mit **Ist er live?**.
  </Accordion>
  <Accordion title="Es erscheint ein anderer Assistent">
    Auf der Seite steht der Code eines anderen Assistenten. Ersetzen Sie ihn durch den Code von **Einbauen** dieses Assistenten.
  </Accordion>
  <Accordion title="Er erscheint nur auf einer Domain">
    Tragen Sie weitere Domains unter **Einbauen › Weitere Websites** ein.
  </Accordion>
</AccordionGroup>
