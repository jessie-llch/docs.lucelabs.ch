title: "Gespräche"

---

Unter **Gespräche** lesen Sie jedes Gespräch Ihres Assistenten. Wählen Sie links ein Gespräch, rechts sehen Sie es ganz.

## Oben auf der Seite

| Zahl | Bedeutung |
| --- | --- |
| **Gespräche, 30 Tage** | mit der Zahl der Fragen |
| **Brauchen Sie** | Fragen, auf die Ihr Assistent keine Antwort hatte |
| **Zeit gespart, etwa** | eine Schätzung: wenn eine Frage Sie ein paar Minuten kostet |

## Filtern

- **Alle**
- **Nicht beantwortet:** Gespräche mit offenen Fragen.
- **Mit Anfrage:** Gespräche, in denen der Besucher eine Anfrage gesendet hat.
- **Assistent:** nur die Gespräche eines Assistenten.

Markierungen in der Liste: **Nicht beantwortet**, **Anfrage**, **Wartet auf eine Person** und **Live**.

## Aus einem Gespräch lernen

- **Antwort verbessern:** War eine Antwort falsch oder fehlte sie, schreiben Sie die richtige. Sie gilt ab sofort. [Fragen und Antworten](/assistent/fragen-und-antworten)
- **Anfrage aus diesem Gespräch ansehen:** führt zur Anfrage unter [Anfragen](/alltag/anfragen).
- **Zusammenfassen:** zwei Sätze dazu, was der Besucher möchte.

## Selbst antworten

Möchte ein Besucher mit einer Person sprechen, übernehmen Sie das Gespräch direkt hier. [Live-Chat](/alltag/live-chat)

<Info>
  Den Text eines Gesprächs können Sie 7 Tage lang lesen. Danach wird er gelöscht.
</Info>
