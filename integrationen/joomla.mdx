Ihr Assistent kommt mit einer Zeile Code auf Ihre Joomla-Website. Die passende Anleitung zeigt Ihnen das Dashboard auch unter **Einbauen › Wo Sie ihn einfügen**.

## Was Sie brauchen

- Zugang zum Joomla-Backend mit Rechten für Site Templates.
- Ihre Website ist unter **Einbauen › Ihre Website** eingetragen.
- Eine laufende Testphase oder einen Plan. Alle Pläne.

## Schritt für Schritt

<Steps>
  <Step title="Code kopieren">
    Auf der Seite Ihres Assistenten unter **Einbauen** auf **Code kopieren** klicken.
  </Step>
  <Step title="Vorlage öffnen">
    In Joomla **System › Site Templates** und Ihre Vorlage öffnen, zum Beispiel «Cassiopeia Details and Files».
  </Step>
  <Step title="Code einfügen">
    Die Datei `index.php` öffnen und den Code direkt über `</body>` einfügen.
  </Step>
  <Step title="Speichern">
    Auf **Speichern & Schliessen** klicken.
  </Step>
</Steps>

Danach prüfen Sie mit [Ist er live?](/start/ist-er-live), ob alles stimmt.

## Was Besucher sehen

Unten rechts den Chat-Knopf, auf jeder Seite. Aussehen und Position stellen Sie unter [Aussehen](/assistent/aussehen) ein.

## Wenn es nicht klappt

<AccordionGroup>
  <Accordion title="Nach einem Update ist der Chat weg">
    Ein Update der Vorlage kann `index.php` überschreiben. Fügen Sie den Code dann erneut ein.
  </Accordion>
  <Accordion title="Der Chat erscheint nicht">
    Wurde die Website nach dem Einfügen veröffentlicht? Laden Sie die Seite neu, am besten in einem privaten Fenster. Prüfen Sie dann mit **Ist er live?**.
  </Accordion>
  <Accordion title="Es erscheint ein anderer Assistent">
    Auf der Seite steht der Code eines anderen Assistenten. Ersetzen Sie ihn durch den Code von **Einbauen** dieses Assistenten.
  </Accordion>
  <Accordion title="Er erscheint nur auf einer Domain">
    Der Chat erscheint nur auf eingetragenen Websites. Tragen Sie weitere Domains unter **Einbauen › Weitere Websites** ein.
  </Accordion>
</AccordionGroup>

<Tip>
  Macht Ihre Website jemand anders? Unter **An meinen Webentwickler senden** schicken Sie Code und Anleitung per E-Mail.
</Tip>
