Besucher öffnen den Chat mit dem Knopf auf Ihrer Website. Sie schreiben in ihrer Sprache und bekommen die Antwort in derselben.

## Was Besucher sehen

- **Die Antwort mit Quelle:** Unter jeder Antwort steht, von welcher Seite sie stammt, zum Beispiel «Quellen: Preise».
- **Vorgeschlagene Fragen** zum Antippen.
- **Karten**, wo es passt: Produkte, Termine, Tischreservationen oder die Newsletter-Anmeldung.
- **Einen Hinweis**, dass Antworten von einer KI geschrieben werden, mit Link zum Datenschutz.

Ein Klick auf den Namen Ihres Assistenten oben im Chat öffnet **Über diesen KI-Assistenten**: dass er keine Person ist, dass Antworten unvollständig oder falsch sein können und wie mit Daten umgegangen wird.

## Das Chat-Menü

Oben im Chat öffnen Besucher das **Chat-Menü**:

| Eintrag | Was passiert |
| --- | --- |
| **Neuer Chat** | Ein leeres Gespräch beginnt. |
| **Letzte Chats** | Frühere Gespräche in diesem Browser. |
| **Chat herunterladen** | Das Gespräch als Datei. |
| **Mit einer Person sprechen** | Ihr Team wird gerufen. [Live-Chat](/alltag/live-chat) |
| **Chat beenden** | Das Gespräch wird abgeschlossen. |

Kommt ein Besucher zurück, fragt der Chat: «Willkommen zurück! Möchten Sie Ihren letzten Chat fortsetzen?»

<Info>
  Die letzten Chats bleiben 7 Tage im Browser des Besuchers. Auch Sie können sie 7 Tage im Dashboard lesen, danach wird der Text gelöscht.
</Info>

## Wenn er nicht weiterweiss

Dann sagt Ihr Assistent es ehrlich und zeigt, wie man Sie erreicht. Besucher können Ihnen direkt im Chat eine Anfrage senden. [Anfrage ans Team](/chat/kontaktformular)
