# Lucelabs Hilfe

Hilfeseiten für Kundinnen und Kunden von Lucelabs, online unter docs.lucelabs.ch (Mintlify).

- Seiten: `.mdx`-Dateien, Navigation in `docs.json`.
- Ein Push auf `main` veröffentlicht die Änderungen.
- Vorschau lokal: `npx mint dev` (Node 20.17 oder neuer).
- Schreibstil: kurz, «Sie», Schweizer «ss», keine Werbewörter.
