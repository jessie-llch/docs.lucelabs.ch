Ihr Assistent erkennt Ihre Produkte beim Lesen der Website: Name, Preis, Varianten, Bild. Fragt ein Besucher danach, zeigt er sie als Karte im Chat. Sie richten dafür nichts ein.

## Das Wichtigste

| | |
| --- | --- |
| **Plan** | Produktkarten ab Medium, oder Basic mit der Zusatzoption «Tabellen, Statistiken und Karten». Ohne Karten nennt Ihr Assistent die Produkte im Text. |
| **WooCommerce, Shopify** | Variante wählen, **In den Warenkorb**. |
| **Wix, Squarespace, Webflow, Jimdo** | **Produkt öffnen**, dann kaufen wie gewohnt. |
| **Preise** | kommen aus Ihrer Website, nie von der KI |

Ihr Assistent legt nie selbst etwas in den Warenkorb, bestellt oder bezahlt.

## Gut zu wissen

<AccordionGroup>
  <Accordion title="Die Produktkarte">
    Ein Tipp öffnet die Details: Bild, Text, Preis, Varianten, ob das Produkt an Lager oder ausverkauft ist. Dazu **In den Warenkorb** oder **Produkt öffnen**. Ob etwas an Lager ist, sagt er nur, wenn es auf Ihrer Website steht.
  </Accordion>
  <Accordion title="Bestellstatus">
    Kunden von WooCommerce-Shops fragen im Chat nach ihrer Bestellung, mit Bestellnummer und E-Mail. [WooCommerce](/integrationen/woocommerce#bestellstatus)
  </Accordion>
  <Accordion title="Es werden keine Produkte erkannt">
    Ihr Assistent erkennt Produkte, wenn Ihr Shop strukturierte Produktdaten (schema.org) veröffentlicht. Die grossen Shop-Systeme tun das von selbst. Neue oder geänderte Produkte erscheinen, nachdem die [Website neu gelesen](/assistent/website-lesen) wurde.
  </Accordion>
</AccordionGroup>
