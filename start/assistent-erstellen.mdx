---
title: "Assistent erstellen"
description: "Vom Konto bis zum ersten Gespräch, in etwa fünf Minuten."
---

<Steps>
  <Step title="Konto eröffnen">
    Auf [lucelabs.ch](https://lucelabs.ch) auf «7 Tage gratis testen» klicken. Sie brauchen keine Kreditkarte.
  </Step>
  <Step title="Website eintragen">
    Geben Sie die Adresse Ihrer Website ein, zum Beispiel `www.ihr-betrieb.ch`. Ihr Assistent beginnt sofort, sie zu lesen.
  </Step>
  <Step title="Kurz beschreiben, was fehlt">
    Unter **Wissen › Was nicht auf der Website steht** ergänzen Sie, was Besucher oft fragen, aber nirgends steht. Zum Beispiel Parkplätze oder wie lange eine Offerte dauert. [Mehr dazu](/assistent/wissen)
  </Step>
  <Step title="Testen">
    Stellen Sie im Chat Fragen, wie es ein Besucher tun würde. [So testen Sie gut](/start/testen)
  </Step>
  <Step title="Einbauen">
    Fügen Sie eine Zeile Code auf Ihrer Website ein. [Anleitung](/start/einbauen)
  </Step>
</Steps>

Im Dashboard zeigt Ihnen der **Startplan**, was noch offen ist.

<Tip>
  Keine Zeit? Wir richten Ihren Assistenten mit Ihnen ein, einmalig ab CHF 290.
</Tip>

## Das Dashboard

Jeder Assistent hat vier Bereiche:

| Bereich | Was Sie dort tun |
| --- | --- |
| **Wissen** | Website, Ergänzungen, Anrede und Länge der Antworten, Fragen und Antworten |
| **Aussehen** | Begrüssung, vorgeschlagene Fragen, Farben, Logo, Position |
| **Funktionen** | Termine, Shop, Newsletter, Verbindungen zu Ihren Systemen |
| **Einbauen** | Code für Ihre Website und Anleitungen |

Änderungen werden automatisch gespeichert.
