Den Code finden Sie auf der Seite Ihres Assistenten unter **Einbauen**. Er sieht so aus:

```html
<script src="https://lucelabs.ch/js/chatbot-embed.js" data-chatbot-id="IHRE-ID" defer></script>
```

Fügen Sie ihn auf jeder Seite ein, am besten direkt vor `</body>`. Mit **Code kopieren** haben Sie ihn in der Zwischenablage. Danach erscheint unten rechts der Chat-Knopf.

<Info>
  Der Chat erscheint auf Ihrer Website, solange Ihre Testphase oder Ihr Plan läuft. Testen können Sie im Dashboard jederzeit.
</Info>

## Ihre Websites

Ihr Assistent erscheint nur auf den Websites, die Sie eingetragen haben. Die Hauptadresse steht unter **Einbauen › Ihre Website**, ohne `https://`, zum Beispiel `beispiel.ch`.

Unter **Weitere Websites** fügen Sie zusätzliche Adressen hinzu, etwa einen Shop auf einer eigenen Domain. Mit **auch Subdomains** gilt die Adresse auch für `shop.beispiel.ch` und ähnliche. Wie viele Websites Sie eintragen können, hängt vom [Plan](/konto/plaene) ab.

<Tip>
  Macht Ihre Website jemand anders? Unter **An meinen Webentwickler senden** schicken Sie Code und Anleitung per E-Mail. Antworten gehen an Sie.
</Tip>
