Sie erreichen das Dashboard unter [lucelabs.ch/dashboard](https://lucelabs.ch/dashboard/).

## Das Menü

| Menüpunkt | Was Sie dort finden |
| --- | --- |
| **Übersicht** | Ihr Startplan, die Zahlen dieser Woche und Ihre Assistenten |
| **Gespräche** | Was Besucher gefragt haben und was Ihr Assistent geantwortet hat. [Mehr](/alltag/gespraeche) |
| **Assistenten** | Die Seite Ihres Assistenten mit Wissen, Aussehen, Funktionen und Einbauen |
| **Verbindungen** | Alles, womit Ihr Assistent verbunden ist. [Mehr](/funktionen/verbindungen) |
| **Analytics** | Häufige Fragen, offene Fragen und Uhrzeiten. [Mehr](/alltag/statistik) |
| **Anfragen** | Kontaktanfragen aus dem Chat. [Mehr](/alltag/anfragen) |
| **Nutzung** | Wie viele Gespräche Ihres Plans verbraucht sind. [Mehr](/konto/zusatzgespraeche) |
| **Team & Firma** | Personen einladen und Rollen vergeben. [Mehr](/konto/team) |
| **Abo & Rechnungen** | Plan, Zahlung, Zusatzoptionen, Kündigung. [Mehr](/konto/abo-verwalten) |
| **Mein Konto** | Profil, Sicherheit, Benachrichtigungen. [Mehr](/konto/einstellungen) |
| **Hilfe & Support** | Eine Nachricht direkt an uns. [Mehr](/hilfe/support) |
| **Systemstatus** | Ob alles läuft. |

Unten im Menü wechseln Sie die Sprache (DE, EN, FR, IT) und zwischen hellem und dunklem Design.

Solange Ihr Assistent noch nicht auf Ihrer Website ist, zeigt die Übersicht, was fehlt. Zum Beispiel die Adresse Ihrer Website, ein ausgeschalteter Assistent oder ein fehlender Plan. [Ist er live?](/start/ist-er-live)

## Gesparte Zeit

Die Übersicht schätzt, wie viel Zeit Ihr Assistent Ihnen spart: beantwortete Fragen × 3 Minuten × Ihre Stundenkosten. Die Stundenkosten ändern Sie unter **Mein Konto**. Es ist eine Schätzung.

## Hilfe im Dashboard

- **KI fragen:** Ein Assistent für Ihr Konto. Er beantwortet Fragen zum Dashboard, öffnet Seiten und füllt Felder aus. Er schlägt nur vor: Nichts ändert sich ohne Ihr OK oder Speichern.
- **Suchen:** Springen Sie zu Seiten, Assistenten oder offenen Fragen. Auf dem Computer auch mit `Ctrl K`.
- **Rundgang wiederholen (1 Min.):** Die fünf wichtigsten Dinge, unten im Menü.
