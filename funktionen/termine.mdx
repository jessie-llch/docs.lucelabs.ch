Fragt ein Besucher nach einem Termin, zeigt Ihr Assistent freie Zeiten als Knöpfe. Gebucht wird im Chat, mit Ihrem eigenen Lucelabs-Kalender. Wählen Sie, womit Sie arbeiten:

<CardGroup cols={2}>
  <Card title="Lucelabs-Kalender" icon="calendar-check" href="/integrationen/lucelabs-kalender">
    Buchungen direkt im Chat. Hier fangen Sie an.
  </Card>
  <Card title="Outlook" icon="calendar" href="/integrationen/outlook">
    Belegte Zeiten ausblenden, Buchungen eintragen.
  </Card>
  <Card title="Google Kalender" icon="calendar-days" href="/integrationen/google-kalender">
    Öffentliche Anlässe. Termine abgleichen auf Anfrage.
  </Card>
  <Card title="Calendly" icon="clock" href="/integrationen/calendly">
    Freie Zeiten im Chat, gebucht wird auf Calendly.
  </Card>
</CardGroup>

Für Restaurants gibt es stattdessen [Tischreservierungen](/funktionen/reservationen).

## Das Wichtigste

| | |
| --- | --- |
| **Plan** | ab Medium, oder Basic mit der Zusatzoption «Tabellen, Statistiken und Karten» |
| **Wo einrichten** | **Funktionen › Termine und Tische** |
| **Doppelt gebucht?** | Nie. Eine Zeit kann nur einmal gebucht werden. |
| **Ohne Termine im Chat** | Ihr Assistent bestätigt nie selbst einen Termin. Er verlinkt auf Ihre Buchungsseite oder bietet die [Anfrage ans Team](/chat/kontaktformular) an. |

<Note>
  Name und Kontaktangaben aus einer Buchung werden 30 Tage nach dem Termin gelöscht.
</Note>
