Ihr Assistent kommt mit einer Zeile Code auf Ihre TYPO3-Website. Danach beantwortet er Fragen Ihrer Besucher auf jeder Seite.

## Was es kann

| | |
| --- | --- |
| **Chat auf jeder Seite** | unten rechts der Chat-Knopf |
| **Aussehen** | Farben, Logo und Position unter [Aussehen](/assistent/aussehen) |
| **Anleitung im Dashboard** | auch unter **Einbauen › Wo Sie ihn einfügen** |

## Was Sie brauchen

- Zugang zum TYPO3-Backend mit Rechten für Templates bzw. TypoScript.
- Ihre Website unter **Einbauen › Ihre Website** eingetragen.
- Eine laufende Testphase oder einen Plan. Alle Pläne.

## Einrichten

<Steps>
  <Step title="Code kopieren">
    Auf der Seite Ihres Assistenten unter **Einbauen** auf **Code kopieren** klicken.
  </Step>
  <Step title="Template öffnen">
    In TYPO3 **Web › Template** öffnen (ab TYPO3 12: **Site Management › TypoScript**) und die Startseite wählen.
  </Step>
  <Step title="Zwei Zeilen einfügen">
    Im Setup ans Ende zwei Zeilen einfügen. Nach `value = ` folgt direkt Ihr Code:

    ```text
    page.footerData.9999 = TEXT
    page.footerData.9999.value = <script src="https://lucelabs.ch/js/chatbot-embed.js" data-chatbot-id="IHRE-ID" defer></script>
    ```
  </Step>
  <Step title="Cache leeren">
    Speichern und den Cache leeren (Blitz-Symbol oben).
  </Step>
  <Step title="Prüfen">
    Mit [Ist er live?](/start/ist-er-live) prüfen, ob alles stimmt.
  </Step>
</Steps>

## Wenn etwas nicht klappt

<AccordionGroup>
  <Accordion title="Nach dem Speichern ändert sich nichts">
    TYPO3 zeigt oft noch die alte Seite. Leeren Sie alle Caches und laden Sie die Seite neu.
  </Accordion>
  <Accordion title="Der Chat erscheint nicht">
    Wurde die Website nach dem Einfügen veröffentlicht? Laden Sie die Seite neu, am besten in einem privaten Fenster. Prüfen Sie dann mit **Ist er live?**.
  </Accordion>
  <Accordion title="Es erscheint ein anderer Assistent">
    Auf der Seite steht der Code eines anderen Assistenten. Ersetzen Sie ihn durch den Code von **Einbauen** dieses Assistenten.
  </Accordion>
  <Accordion title="Er erscheint nur auf einer Domain">
    Tragen Sie weitere Domains unter **Einbauen › Weitere Websites** ein.
  </Accordion>
</AccordionGroup>
